# 🌤️ Météo Direct - Weather App

Une application web minimaliste permettant de consulter la météo en temps réel pour n'importe quelle ville dans le monde.
Ce projet a été réalisé pour mettre en pratique la consommation d'API REST avec JavaScript moderne.

## 🚀 Fonctionnalités
* **Recherche temps réel :** Connexion à l'API OpenWeatherMap.
* **Données affichées :** Température, Description (Ciel), Humidité, Vent.
* **Interface dynamique :** Manipulation du DOM sans rechargement de page.
* **Design Responsive :** Interface épurée et adaptative (CSS3 Flexbox).

## 🛠️ Stack Technique
* **Langages :** HTML5, CSS3, JavaScript (ES6+).
* **API :** OpenWeatherMap (Fetch API / Async Await).
* **Gestion d'erreurs :** Traitement des cas 404 (Ville introuvable) et erreurs réseaux.
